    2. Implementation:
       ```python
       BASE = Path("data/processed/parcels.parquet")
       OUT = Path("viz/src/data/parcels.geojson")
       PROPERTY_COLS = ["pams_pin", "block", "lot", "mun", "prop_loc"]  # D-60 stable identity only

       def main() -> int:
           if not BASE.exists():
               print(f"ERROR: missing {BASE}; run `make ingest-njgin` first", file=sys.stderr)
               return 2
           gdf = read_geoparquet(BASE)
           if len(gdf) == 0:
               print("ERROR: zero parcels — refusing to declare success", file=sys.stderr)
               return 2

           # Restrict properties: D-65 owner-name footprint isolation.
           keep = [c for c in PROPERTY_COLS if c in gdf.columns] + [gdf.geometry.name]
           gdf = gdf[keep]

           # Reproject EPSG:3424 → EPSG:4326 (Leaflet wants WGS84).
           gdf_wgs = gdf.to_crs(constants.CRS_EXPORT)

           # Atomic write
           OUT.parent.mkdir(parents=True, exist_ok=True)
           tmp = OUT.with_suffix(".geojson.tmp")
           if tmp.exists():
               tmp.unlink()
           gdf_wgs.to_file(tmp, driver="GeoJSON")
           tmp.replace(OUT)
           print(f"Wrote {len(gdf_wgs)} features → {OUT}")
           return 0
       ```

       The `keep` filter is the D-65 enforcement point. If the parquet schema includes any of `owner_name, owner_mailing_address, owner_*` columns, they are excluded by virtue of the whitelist. Document the actual columns present in the SUMMARY.
