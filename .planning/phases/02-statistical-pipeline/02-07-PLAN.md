<objective>
Implement the **Python port of `assessr::detect_chasing()`** (TEST-01) — a 30-line direct translation from the CCAO R package source (RESEARCH.md §4, retrieved 2026-04-29 commit master).

The function detects **sales chasing** — selective reappraisal of recently sold properties to match sale prices, an IAAO violation that masks true assessment quality. It returns TRUE/FALSE based on TWO heuristic signatures AND-combined:

1. **CDF gap method (`detect_chasing_cdf`):** the maximum gap in the empirical CDF of sale ratios exceeds `cdf_gap=0.03` AND occurs at a ratio strictly inside `bounds=(0.98, 1.02)`.
2. **Distribution method (`detect_chasing_dist`):** the actual fraction of ratios in `bounds` exceeds the fraction expected under a normal distribution with the same mean/SD.

**Critical fidelity requirements (RESEARCH.md §4.2):**
- ECDF computation: `np.arange(1, n+1) / n` evaluated at sorted ratios — NOT `scipy.stats.ecdf` (different step boundaries).
- AND-combine for `method='both'` (the default) — both methods must return TRUE.
- `dist` method MUST accept a seeded `rng` parameter (R's `rnorm` is non-deterministic; we make ours deterministic per D-67).
- Ratio = sale_assessment / sale_price (NOT inverted; assessor-side / market price).
- Soft warning fires for N<30 but does NOT short-circuit. Fair Haven full-sample post-ADP has 700-900 ratios — well above threshold.

Scope: **full-sample only** in 2014-2025 post-ADP window (D-55). Cohort-level runs are excluded (the planning context flags them as underpowered).

Ships the canonical CDF-with-cliff plot via Altair (RESEARCH.md §4.3). Flags individual outlier parcels (those whose ratio falls inside the gap location) in an overlay JSON for ParcelMap popup display.

Purpose: **The single most persuasive Phase-2 artifact** (per CONTEXT D-58 plan 7 description). A TRUE verdict combined with non-trivial Berry shift = v2 justified per the MVP decision gate.
Output: 1 JSON result, 1 chart spec, 1 overlay JSON, 1 Astro page.

```python
def detect_chasing_cdf(ratio, bounds=(0.98, 1.02), cdf_gap=0.03):
    assert 0 < cdf_gap < 1
    sorted_ratio = np.sort(ratio[~np.isnan(ratio)])
    if len(sorted_ratio) < 2: return False
    n = len(sorted_ratio)
    cdf = np.arange(1, n + 1) / n
    diffs = np.diff(cdf)
    if len(diffs) == 0: return False
    idx = int(np.argmax(diffs))
    diff_loc = float(sorted_ratio[idx])
    return bool(diffs[idx] > cdf_gap and bounds[0] < diff_loc < bounds[1])

def detect_chasing_dist(ratio, bounds=(0.98, 1.02), n_sim=10_000, rng=None):
    if rng is None: rng = np.random.default_rng(seed=42)
    r = ratio[~np.isnan(ratio)]
    if len(r) < 2: return False
    mu, sigma = float(np.mean(r)), float(np.std(r, ddof=1))
    ideal = rng.normal(mu, sigma, size=n_sim)
    pct_ideal  = float(np.mean((ideal >= bounds[0]) & (ideal <= bounds[1])))
    pct_actual = float(np.mean((r     >= bounds[0]) & (r     <= bounds[1])))
    return pct_actual > pct_ideal

def detect_chasing(ratio, method='both', bounds=(0.98, 1.02), cdf_gap=0.03, rng=None):
    assert method in ('cdf', 'dist', 'both')
    r = np.asarray(ratio, dtype=float)
    if r.size <= 2: raise ValueError("Need length(ratio) > 2")
    if r.size < 30:
        warnings.warn("Sales chasing detection can be misleading when applied to small samples (N < 30)...")
    if method == 'cdf': return detect_chasing_cdf(r, bounds=bounds, cdf_gap=cdf_gap)
    if method == 'dist': return detect_chasing_dist(r, bounds=bounds, rng=rng)
    return (detect_chasing_cdf(r, bounds=bounds, cdf_gap=cdf_gap)
            and detect_chasing_dist(r, bounds=bounds, rng=rng))
```

           if rng is None:
               rng = np.random.default_rng(seed=constants.RANDOM_SEED)
           r = np.asarray(ratio, dtype=float)
           r = r[~np.isnan(r)]
           sorted_r = np.sort(r)
           n = len(sorted_r)
           cdf_arr = np.arange(1, n + 1) / n
           diffs = np.diff(cdf_arr)
           idx = int(np.argmax(diffs)) if len(diffs) > 0 else -1
           cdf_max_gap = float(diffs[idx]) if idx >= 0 else 0.0
           cdf_max_gap_location = float(sorted_r[idx]) if idx >= 0 else float('nan')
           n_inside = int(np.sum((r >= bounds[0]) & (r <= bounds[1])))
           n_outside = n - n_inside
           cdf_result = bool(cdf_max_gap > cdf_gap and bounds[0] < cdf_max_gap_location < bounds[1])
           dist_result = detect_chasing_dist(r, bounds=bounds, rng=rng)
           return {
               'verdict': cdf_result and dist_result,
               'test_name': "assessr::detect_chasing(method='both')",
               'method': 'both',
               'cdf_method_result': cdf_result,
               'dist_method_result': dist_result,
               'cdf_max_gap': cdf_max_gap,
               'cdf_max_gap_location': cdf_max_gap_location,
               'n_inside_band': n_inside,
               'n_outside_band': n_outside,
               'n_total': n,
               'ratio_band': list(bounds),
               'scope_window': [int(constants.CDF_TEST_YEAR_MIN), int(constants.CDF_TEST_YEAR_MAX)],
