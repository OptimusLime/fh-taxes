**B. `src/fairhaven_tax/ingest/pams_pin.py`** — PAMS_PIN constructor:

```python
"""PAMS_PIN construction. The join key across NJGIN and SR1A.

Format: f"{district}_{block}_{lot}_{qualifier}" with qualifier="" when absent.
district zero-padded to 2 chars; block/lot preserved as string (leading zeros
and letter suffixes are meaningful in MOD-IV).
"""
from __future__ import annotations


def build_pams_pin(district, block, lot, qualifier=None) -> str:
    d = str(district).strip().zfill(2)
    b = str(block).strip()
    l = str(lot).strip()
    q = (qualifier or "").strip()
    if q.lower() in {"none", "nan"}:
        q = ""
    return f"{d}_{b}_{l}_{q}"


def parse_pams_pin(pin: str) -> tuple[str, str, str, str]:
    parts = pin.split("_")
    if len(parts) != 4:
        raise ValueError(f"invalid pams_pin: {pin!r} (expected 4 parts)")
    return parts[0], parts[1], parts[2], parts[3]
```

**D. `src/fairhaven_tax/persist/parquet_io.py`**:

```python
"""Parquet / GeoParquet read+write helpers. D-01: never SQLite, never PostGIS."""
from __future__ import annotations
from pathlib import Path
import geopandas as gpd
import pandas as pd
import pyarrow as pa
import pyarrow.parquet as pq

PROCESSED_DIR = Path("data/processed")


def ensure_processed_dir() -> Path:
    PROCESSED_DIR.mkdir(parents=True, exist_ok=True)
    return PROCESSED_DIR


def write_parquet(df, path, schema=None, compression="zstd", metadata=None) -> Path:
    p = Path(path)
    p.parent.mkdir(parents=True, exist_ok=True)
    table = pa.Table.from_pandas(df, schema=schema, preserve_index=False)
    if metadata:
        merged = dict(table.schema.metadata or {})
        for k, v in metadata.items():
            merged[k.encode()] = v.encode()
        table = table.replace_schema_metadata(merged)
    pq.write_table(table, p, compression=compression)
    return p


def write_geoparquet(gdf, path, compression="zstd") -> Path:
    p = Path(path)
    p.parent.mkdir(parents=True, exist_ok=True)
    if gdf.crs is None:
        raise ValueError("GeoDataFrame has no CRS; refusing to write")
    gdf.to_parquet(p, compression=compression)
    return p


def read_parquet(path) -> pd.DataFrame:
    return pq.read_table(Path(path)).to_pandas()


def read_geoparquet(path) -> gpd.GeoDataFrame:
    return gpd.read_parquet(Path(path))
```

2. Open the archive (`.zip` containing CSV/TXT/DBF; per-year format may vary). Detect format: if zip contains a `.csv` or `.txt`, read as delimited (try `,` then `|` then tab). If it contains `.dbf`, read with `geopandas`/`fiona` or `dbfread`. Initial implementation: handle CSV/TXT only and emit a clear error for DBF telling the implementer to add support; this keeps the surface tight.
3. Apply `mapping` from YAML to rename columns to canonical names. Any source column not in `mapping` is dropped (its rows are NOT rejected — only unmapped rows go to rejections, see step 6).
4. Apply `types` coercions:
   - `sale_date: date` — try `pd.to_datetime(s, format="%m/%d/%Y", errors="coerce")` then fall back to `errors="coerce"` with mixed format. Rows that become `NaT` go to rejections with `unparseable_date`.
   - `sale_price: decimal` — strip `$` and `,`, `Decimal(...)`. Rows where this fails → rejections with `unparseable_price`.
   - `nu_code: string_zfill_2` — `str(x).strip().zfill(2)`. NOTE: NU code "0" padded to "00" would collide with the constants set; instead handle as: bare "0"/"00" both normalize to "0", others zfill(2). Implementation: `lambda x: "0" if str(x).strip() in {"0", "00"} else str(x).strip().zfill(2)`. This preserves the canonical SR1A_ARMS_LENGTH_NU_CODES set.
   - `district: string_zfill_2` — `str(x).strip().zfill(2)`.
   - `property_class: string` — `str(x).strip()`.
5. Build `parcel_pin` via `build_pams_pin(district, block, lot, qualifier)` for every row.
6. Apply filters in this exact order, routing failures to rejections:
   - **a.** `district != constants.SR1A_DISTRICT_FAIR_HAVEN` → reject with `district_not_fair_haven`.
   - **b.** `district/block/lot` any null → reject with `missing_required_field`.
   - **c.** `nu_code not in constants.SR1A_ARMS_LENGTH_NU_CODES` → reject with `nu_code_not_arms_length`.
7. The surviving rows form `sales_df` with columns per `docs/schemas/sales.md`. Add `source_file` (archive filename) and `source_year` (int16).
8. The rejected rows form `rejections_df` per `docs/schemas/rejections.md` with `deed_ref` = f"{deed_book}/{deed_page}" when present.

`parse_sr1a_all`: glob `{snapshot_dir}/sr1a-*.zip`, parse each via `parse_sr1a_year`, concatenate, return `(sales_all, rejections_all)`.

    Diff threshold: |sr1a_date - modiv_date| > 180 days OR |price_pct_diff| > 5%.

`resolve_last_arms_length_sale` implementation:
- `sales_df.sort_values(["parcel_pin","sale_date","sale_price"], ascending=[True,False,False]).drop_duplicates("parcel_pin", keep="first")` — gives MAX(date) tie-break MAX(price).

`reconcile_last_sale` implementation:
- Left-join resolved last sale onto parcels by `pams_pin == parcel_pin`.
- Set `last_sale_source = "sr1a"` where SR1A had a value, else `"modiv"` if MOD-IV last-sale columns are populated, else null. When source is `"modiv"`, copy MOD-IV columns into last_sale_*.

  - `date_diff_days = |sr1a_date - modiv_date|`
  - `price_pct_diff = |sr1a_price - modiv_price| / max(modiv_price, sr1a_price)` (avoid div by zero)
- Emit a `reconciliation_diffs_df` row when `date_diff_days > 180` OR `price_pct_diff > 0.05`. Columns: `parcel_pin`, `sr1a_sale_date`, `sr1a_sale_price`, `sr1a_nu_code`, `modiv_sale_date`, `modiv_sale_price`, `modiv_nu_code`, `date_diff_days`, `price_pct_diff`.
