<objective>
Wire the seven Phase-2 plans into a single reproducible pipeline (D-67) plus a smoke-test verifier (D-68) that gsd-verifier and the user can run to confirm phase completion.

Includes:
1. **`scripts/run_phase2.sh`** — POSIX shell with `set -euo pipefail`, calls `make phase2`. Lightweight wrapper so `bash scripts/run_phase2.sh` and `make phase2` are functionally equivalent (D-67).
2. **`scripts/verify_phase2.py`** — Python smoke gate. Reads each expected artifact, validates schema/keys per the contracts established in Plans 1-7. Exits 0/1/2 per POSIX (PATTERNS.md S3).
3. **Makefile `phase2` target** — chains the seven sub-targets in correct dependency order.
4. **Updated `viz/src/pages/index.astro`** — wires the five analysis pages now that they all exist.
5. **`tests/test_verify_phase2.py`** — synthetic-fixture tests for the verifier (asserting it correctly detects missing/malformed artifacts).
6. **Visual checkpoint** — operator runs `make phase2 && cd viz && npm run dev` and clicks through all five pages, confirming everything renders with real data.

Purpose: Phase 2 is "done" when one command produces all artifacts and one verifier gates them. Without this, downstream Phase 3 (public artifact + Daniel's Law publication) cannot start because it inherits both the artifacts and the verifier as a smoke-test contract.
Output: 1 shell script, 1 Python verifier, 1 Makefile target, 1 updated Astro page, 1 test file.
</objective>
