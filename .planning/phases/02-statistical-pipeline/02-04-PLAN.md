    - The function:
      a. Reads `sales.parquet` (197 rows). Filters `sale_year ∈ [HEDONIC_TRAIN_YEAR_MIN, HEDONIC_TRAIN_YEAR_MAX]` and `nu_code ∈ ARMS_LENGTH_NU_CODES`.
      b. Reads `prc.parquet`, joins on `pams_pin` (left join from sales). Drops sales where any required feature is null.
      c. Reads `parcels.parquet`, computes parcel centroid (in EPSG:3424), runs `KMeans(n_clusters=k_neighborhood, n_init='auto', random_state=seed)` on `(centroid_x, centroid_y)` after StandardScaler. Each parcel gets a `neighborhood_fe ∈ {0..k-1}`.
      d. Joins neighborhood_fe back to the training frame via pams_pin.
      e. Builds the design matrix: `log(sale_price) ~ log(livable_area) + log(lot_size_acres) + year_built + bedrooms + bathrooms + condition + quality_grade + C(neighborhood_fe) + C(sale_year)`. Use statsmodels `formula.api.ols(formula, data=df).fit(cov_type='HC3')`.
      f. Reports R² as `model.rsquared`.
      g. For per-parcel predictions: build the prediction frame for all 2,060 parcels (using prc + parcels join). For parcels missing any feature (the ~1,864 unsold), use median imputation within their neighborhood_fe cluster. Predict `log(true_value)`, exponentiate to dollars. Apply Duan's smearing factor (`mean(exp(residuals))`) to correct for log-retransformation bias (RESEARCH.md §6 — search "Duan" or "smearing").
      h. Apply calibration constant: if `Σ estimated_true_value` deviates from `constants.EXPECTED_AGGREGATE_ASSESSED` by more than 5%, scale ALL predictions by `EXPECTED_AGGREGATE_ASSESSED / Σ estimated_true_value` and log the calibration factor (MODEL-03 explicitly permits this).

    - `coefficient_chart(fit) -> alt.Chart` returns an Altair chart (point+errorbar) showing each coefficient with 95% CI. x = term name, y = estimate, errorbar from `ci_lo` to `ci_hi`.
    - `residual_chart(fit) -> alt.Chart` returns predicted-vs-actual scatter with 45° reference line. x = `predicted`, y = `actual`, with `tooltip=['pams_pin','sale_year','residual']`.
    - `choropleth_chart_spec(predictions, parcels_geojson_path) -> dict` returns a Vega-Lite spec dict (NOT an alt.Chart — Altair's geo support requires TopoJSON; we hand-author the Vega-Lite spec to consume parcels.geojson with a join on `pams_pin`). The spec has `data: {url: '/data/parcels.geojson', format: {type: 'json', property: 'features'}}` and a `transform: [{lookup: 'properties.pams_pin', from: {data: {url: '/data/overlays/estimated_true_value.json'}, key: 'pams_pin', fields: ['estimated_true_value']}}]`. The chart uses `mark: 'geoshape'` with `color: {field: 'estimated_true_value', type: 'quantitative', scale: {scheme: 'viridis'}}`. NOTE: this spec uses URL-referenced data per the researcher-flagged Vega-Lite 5000-row inline limit.

    - All Decimal hygiene: cast Decimal → float at the statsmodels boundary (`_to_float` helper per PATTERNS.md S5); cast back to Decimal when writing the predictions parquet.
